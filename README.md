# IPL 2026 — Static one-pager

A single-file static site. Deploys on Vercel with zero build configuration.

## Files

- `index.html` — the entire page (HTML, CSS, JS inline). Fonts pulled from Google Fonts; player photos from Wikimedia Commons. No build step.
- `vercel.json` — clean URLs, security headers, long-cache for static assets.
- `.gitignore` — keeps the repo tidy.

## Deploy

### Option A — Vercel CLI (fastest)

```bash
npm i -g vercel       # one-time
cd ipl-vercel
vercel                # follow prompts; press Enter to accept defaults
vercel --prod         # ship to production
```

### Option B — GitHub + Vercel dashboard

1. Push this folder to a GitHub repo:
   ```bash
   cd ipl-vercel
   git init
   git add .
   git commit -m "IPL 2026 one-pager"
   git branch -M main
   git remote add origin git@github.com:<you>/<repo>.git
   git push -u origin main
   ```
2. Go to [vercel.com/new](https://vercel.com/new), import the repo.
3. Framework Preset: **Other** · Root Directory: `./` · Build Command: *(empty)* · Output Directory: *(empty)*. Click Deploy.

### Option C — Drag-and-drop

1. Zip the contents of `ipl-vercel/` (not the folder itself).
2. Drop the zip on [vercel.com/new](https://vercel.com/new) → "Deploy without Git".

## Local preview

```bash
cd ipl-vercel
python3 -m http.server 5173
# open http://localhost:5173
```

Or with Node:

```bash
npx serve .
```

## Custom domain

Once deployed, in the Vercel dashboard go to **Project → Settings → Domains** and add yours. Vercel handles the SSL.

## Notes

- Player photos load from `upload.wikimedia.org`. They're CC-licensed but external — if Wikimedia is blocked or rate-limits, swap them for self-hosted copies in an `/images/` folder.
- Fonts come from Google Fonts (`fonts.googleapis.com`). For full GDPR self-hosting, download the font files and `@font-face` them locally.
- The 62-match dot grid is generated by JS at page load — it's purely visual, no API calls.
